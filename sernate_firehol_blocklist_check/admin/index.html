Sernate FireHOL Blocklist Check

Check whether this server's public IPv4 addresses appear in FireHOL IP blocklists indexed through the Sernate Blocklist API.

Sernate indexes IPs collected from multiple external blocklist sources. We do not maintain those source lists and cannot remove IPs from them. If a removal is needed, contact the maintainer shown for the relevant feed.
